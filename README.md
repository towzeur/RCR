# RCR: Reliability-Calibrated Routing

This repository hosts the project page, code, and evaluation artifacts for:

**When Neural Collapse Fails to Route: Routing Drift in Continual Learning**  
BMVC 2026

Project page: https://towzeur.github.io/RCR/

## Repository Layout

```text
docs/        Project page served by GitHub Pages.
rcr/         Python package for the RCR scoring head.
scripts/     Reproduction, evaluation, and artifact-generation scripts.
configs/     Dataset and experiment configuration files.
artifacts/   Lightweight generated tables, logs, and metadata.
```

The camera-ready paper and supplementary material are mirrored under
`docs/assets/` so the project page remains self-contained.
